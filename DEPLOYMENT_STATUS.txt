## Deployment Instructions

🌐 STEP 1: Go to Block Explorer

   URL: https://explore-preprod.midnight.network

🔐 STEP 2: Connect Wallet

   Click: "Connect Wallet" → Select "Lace" → Approve

📤 STEP 3: Deploy Each Contract

   For each contract:
   a) Click "Deploy Contract"
   b) Select: autodiscovery-contract/src/managed/[contract-name]
   c) Click "Deploy"
   d) Approve in Lace wallet (sign transaction)
   e) Wait 30-60 seconds for confirmation
   f) **COPY the address shown**
   g) Save to a text file
   h) Repeat for next contract

💾 STEP 4: Save All 6 Addresses

   Format:
   VITE_CONTRACT_DISCOVERY_CORE=03cc52g89494d...
   VITE_CONTRACT_DISCOVERY_PROOF=04dd63h89505e...
   VITE_CONTRACT_DOCUMENT_REGISTRY=05ee74i89616f...
   VITE_CONTRACT_ACCESS_CONTROL=06ff85j89727g...
   VITE_CONTRACT_JURISDICTION_REGISTRY=07gg96k89838h...
   VITE_CONTRACT_EXPERT_WITNESS=08hh07l89949i...

## Common Issues & Solutions

❌ "Wallet not found"
   → Install Lace: https://www.lace.io

❌ "Wrong network"
   → In Lace, click network dropdown → Select "PreProd"

❌ "No DUST balance"
   → Get test tokens: https://faucet.midnight.network

❌ "Deploy button missing"
   → Connect wallet first

❌ "Transaction failed"
   → Wait 30 seconds, ensure funds, try again
