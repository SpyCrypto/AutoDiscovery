## 🌐 Access the Frontend

### Option 1: Direct File Access
Open these in your browser:

RealDeal (Main UI):
  file:///AutoDiscovery/frontend-realdeal/dist/index.html

Demoland (Demo UI):
  file:///AutoDiscovery/frontend-demoland-vite-react/dist/index.html


### Option 2: Using Python HTTP Server

# In PowerShell, from AutoDiscovery directory:

# RealDeal on port 5174:
python -m http.server 5174 --directory .\frontend-realdeal\dist

# OR Demoland on port 5173:
python -m http.server 5173 --directory .\frontend-demoland-vite-react\dist

Then open:
  http://localhost:5174 (RealDeal)
  http://localhost:5173 (Demoland)


### Option 3: Using Node.js HTTP Server

npm install -g http-server

cd frontend-realdeal && http-server dist -p 5174
cd frontend-demoland-vite-react && http-server dist -p 5173

Then open:
  http://localhost:5174 (RealDeal)
  http://localhost:5173 (Demoland)
