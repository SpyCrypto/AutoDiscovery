## TROUBLESHOOTING

"This site can't be reached":
→ Make sure you typed: http://localhost:5174
→ Not https:// - it's http://

"Connection refused":
→ Web server might have stopped
→ Run this in PowerShell:
  cd AutoDiscovery && python -m http.server 5174 --directory frontend-realdeal/dist

Blank page:
→ Press F5 to refresh
→ Wait a few seconds for it to load
