TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Connect Wallet" button missing
   → Refresh page (F5)
   → Clear browser cache
   → Verify Lace is installed

❌ Lace shows "Wrong Network"
   → Open Lace
   → Click network dropdown
   → Select "PreProd"
   → Reload explorer page

❌ "Insufficient Balance" error
   → Go to https://faucet.midnight.network
   → Paste wallet address from Lace
   → Request tokens (wait 1-2 min)
   → Check balance in Lace
   → Try deployment again

❌ Transaction stuck for > 2 min
   → Refresh page
   → Check status in Lace wallet
   → If stuck, try deploying again

❌ "Deploy button" not found
   → Look for menu icon (☰)
   → Check for "Contracts" menu
   → Try scrolling down
   → Check browser console (F12)
